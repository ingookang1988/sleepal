## 🆕 기능 연결 요청 — NFC 거치 자동 실행 ([ADR-401] ①의 보드 구현)

**목표: 폰을 거치대에 올리면 슬립팰 앱이 자동으로 열린다.**

NU40의 SoC(nRF52840)는 **NFC-A 태그 에뮬레이션(NFCT 페리페럴)** 을 지원합니다. 보드가 NDEF URI 레코드(앱 URL)를 태그로 광고하면, 안드로이드 폰이 거치되는 순간 URL을 자동으로 엽니다(화면 켜짐+잠금해제 시). RN 앱이 설치돼 있고 App Links(도메인 연결)가 걸려 있으면 **RN 앱이 직접 열리고**, 미설치면 PWA가 열립니다.

- [ ] **핀맵 확인(선행)** — NU-40 DK 모듈이 NFC1/NFC2(P0.09/P0.10) 안테나 경로를 노출하는지. 참고: 모듈 스펙표(docs/05)에는 NFC가 NU-32에만 표기돼 있어 실물 확인 필요. `NFCPINS` 레지스터가 GPIO로 잡혀 있으면 NFC 비활성이니 함께 확인
- [ ] **안테나** — 모듈에 안테나 미제공이면 루프/플렉스 안테나 부착. 폰 NFC 코일 위치(갤럭시: 후면 중앙~카메라 부근)와 1~2cm 정렬되도록 거치대 슬롯과 조율 필요
- [ ] **펌웨어** — NDEF URI 레코드(T2T) 에뮬레이션. Adafruit bluefruit 코어의 NFC 지원이 제한적일 수 있어 nRF SDK NFC 라이브러리 필요 여부 조사 포함
- [ ] **URL 결정** — PWA 배포 URL vs RN App Link 도메인 (RN 쪽과 함께)
- ⚠ **한계 공유**: System OFF(SLEEPING 이후)에는 NFCT도 꺼집니다 — 보드가 자는 동안의 거치는 자동 실행이 안 되므로, 그 경로가 중요하면 수동 NTAG 스티커(수백 원)를 거치대에 병행 부착하는 폴백([ADR-401] ①)을 유지합니다.
- 보드 에뮬레이션의 장점: URL을 펌웨어로 갱신 가능(배포 URL 변경 시 스티커 재부착 불요).
