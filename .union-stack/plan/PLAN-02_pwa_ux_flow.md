# [PLAN-02] P1 UX 플로우

## 합의한 것 (인간 확정 2026-08-22)
잠들기 전 외로움을 폰 대신 팰이 받는다. 플로우는 4모드 상태 머신이다:

```
PLAY(놀이·대화) → WIND_DOWN(수면 환경) → SLEEP(트래커) → WAKE(기상)
```

| # | 단계 | 요구 | 확정된 기술 결정 |
|---|---|---|---|
| 1 | PLAY | 음성 기반 놀이·대화. 팰은 미니언즈처럼 **고유 발화**(사람 말 아님) — 아기·애완동물과 놀듯이 | 녹음→STT→LLM(Realtime 아님). 팰 응답 = {감정, 표정, 옹알이 톤} — **옹알이는 음절 샘플 절차 합성**(동물의 숲 방식: 오프라인·무비용·캐릭터 통제). LLM은 말이 아니라 반응을 결정한다 |
| 2 | WIND_DOWN | 백색소음·수면 음악 + 볼륨 조절 | 사운드 **앱 내장**(로컬 오디오 + Web Audio — 믹싱·페이드 자유). 유튜브 뮤직은 **공존**: 사용자가 자기 앱으로 백그라운드 재생(프리미엄 필요), 우리는 제어하지 않는다 — 재생 제어 공개 API가 없다 |
| 3 | SLEEP 진입 | 조도 낮음 + 외부 수음 없음 **5분 유지** 또는 명시 명령("나 이제 잘게") | 조도 = 검증된 카메라 조도계 · 수음 = 마이크 RMS(Web Audio). 히스테리시스는 눈 상태 머신과 같은 패턴. 명시 명령은 별도 감지기 없이 **PLAY 대화 채널의 LLM 의도 분류**로 받는다 |
| 4 | SLEEP | 코골이 · 뒤척임 기록 | **폰이 침대가 아니라 팰 안에 있다** — 가속도 불가. v1은 마이크 기반: 코골이(주기적 저주파 에너지) + 소리 기반 뒤척임(거침) + 조도/소음 환경 타임라인. 온디바이스 처리, 원음 무저장, 이벤트만 IndexedDB. 뒤척임 정밀화는 **배게 IMU**(로드맵 → [PHASE-02] 범위 밖 절) |
| 5 | WAKE | 조도 높음 + 외부 수음 **5분 유지** 또는 명시 명령("나 지금 일어났어") | 3번과 대칭. 트래커 종료·기록 저장. 기록 화면은 Vite+React(착수 시점 도입) |

## 시연 시나리오 v1 (인간 합의 2026-08-22 — v0.3 추가)

데모의 관측 가능한 줄거리. 4모드 상태 머신 위에 그대로 얹힌다 — "수면 준비 세션" = PLAY+WIND_DOWN, "수면 트래킹" = SLEEP, "기상" = WAKE.

1. **거치 = 세션 시작.** 폰을 팰(폼팩터)에 거치하면 수면 준비 세션 진입 — 팰이 눈을 뜨고 상호작용 모드. 감지 수단은 [WO-02d-1]에서 결정(후보: 충전 시작 이벤트 · devicemotion 정지 판정).
2. **수면 준비 세션** — 대화·놀이(아래 §놀이 후보). 대화는 **일기의 원료**로 기록된다(→ [CON-03] diary).
3. **SLEEP 진입** — 조도 약화 + 소리 약화 유지, 또는 명시 명령("나 이제 잘래"). 소리 입력은 폰 마이크 RMS에 더해 **보드 HW-484 경로가 열렸다**([ADR-304]) — 어느 쪽을 1차로 쓸지는 [WO-02d-1] 실측 후 결정.
4. **SLEEP 기록** — 시간당 데시벨·시간당 조도. [CON-03]의 분 단위 버킷이 상위 호환(시간당은 기록 화면의 집계 뷰).
5. **밤중 이벤트** — 조도 임계 초과(불 켜짐) → `light_on` 이벤트 기록. 사용자 음성 감지 또는 **거치 이탈** → 기상으로 간주.
6. **알람** — 사용자가 등록, 팰이 깨운다. 알람 반복(스누즈) 횟수로 기상까지 걸린 시간을 추적 → [WO-02d-3].
7. **알람 전 기상**도 기록된다(`wake.beforeAlarm`). 기상 완료 후 그날의 수면 기록 + 대화 일기를 기록 화면([WO-02e-1])에서 본다.

구성 3요소: **슬립팰 앱(팰 런타임) + 트래킹 앱(기록 화면) + 폼팩터(거치)** — 아키텍처 절의 분할과 일치.

## 놀이 후보 (합의 3종 + 제안 — 선정 미확정, [WO-02b-1] 착수 시 확정)

제약: 팰은 사람 말을 하지 않는다(§1 — 옹알이+표정만). 선정 기준: ① 각성도를 **낮추는** 방향인가(수면 준비 맥락) ② 옹알이+표정만으로 팰의 응답이 성립하는가 ③ 기존 자산 재사용(STT/LLM 왕복 · 옹알이 합성 · 사운드 라이브러리 · 호흡 상수).

| 놀이 | 방식 | 기술 비용 | 비고 |
|---|---|---|---|
| 양 세기 (합의) | 사용자가 세면 팰이 옹알이로 따라 센다. 갈수록 팰의 옹알이가 느려지고 졸려한다 — 놀이 자체가 수면 유도 장치 | STT+LLM 왕복 | 팰이 먼저 조는 연출로 WIND_DOWN 자연 전환 |
| 스무고개 (합의) | **팰이 정답을 품고** 사용자가 질문, 팰이 긍정/부정 옹알이+표정으로 답 | STT+LLM 왕복 | 역방향(팰이 질문)은 발화 제약 위반이라 불가 |
| 오늘 하루 대화 (합의) | 사용자가 하루를 이야기하면 팰이 감정 표정으로 반응 | STT+LLM 왕복 | diary 의 핵심 소스 |
| 팰 재워주기 (제안) | 역할 역전 — 사용자가 팰에게 자장가·옛날이야기를 들려주면 팰이 점점 졸린 표정으로 잠든다 | STT+LLM 왕복(감정만) | 남을 재우다 자기가 이완되는 구도. "매일 밤 팰과 함께 잔다" 테제와 직결 |
| 호흡 맞추기 (제안) | 팰의 호흡([ADR-108] 상수 재사용)에 맞춰 같이 숨쉬기 — 마이크 RMS 로 숨소리 동기 감지, 맞으면 흐뭇 표정 | 왕복 불필요(온디바이스) | 느린 호흡의 생리적 이완 효과. 지연 0 |
| 메아리 놀이 (제안) | 사용자가 허밍·소리를 내면 팰이 옹알이 톤으로 흉내낸다(피치 추종) | 왕복 불필요(온디바이스) | STT 실패에도 성립 — R8 폴백을 놀이로 승격한 형태 |
| 숨은 소리 맞히기 (제안) | 팰이 내장 사운드([WO-02c-1] 재사용)를 짧게 틀고 사용자가 맞힌다. 정답이면 기쁨 표정 | STT+LLM 판정 1회 | 수면 사운드 라이브러리의 미리듣기를 겸한다 |
| 오늘 좋았던 일 하나 (제안) | 대화의 축소판 — 감사 한 가지만 말하고 마무리 | STT+LLM 왕복 | 취침 전 감사 회상의 이완 효과 · diary 와 직결 |

시연 추천 조합: **스무고개**(상호작용이 관객에게 명확) + **양 세기**(수면 유도 서사로 SLEEP 전환까지 이어짐).

### 꼬이지 않기 위한 세 경계
1. **파일 경계 = 파트 경계.** 최대 충돌면은 단일 파일 `app/index.html`이다. 그래서 [WO-02a-2](모듈 분할)가 **모든 병렬 작업의 게이트**다 — 분할 전에는 02b~02e 코드 착수 금지. 분할 후 소유: H = `face/`(눈·표정·옹알이)·`ble.js`·`lux.js` / T = `mode.js`·`tracker.js`·`sound.js`·`tracker-app/`(React) / 셸(`index.html`·`sw.js`·`serve.js`) = 02a 소유, 변경은 리드 경유.
2. **계약 경계 — 파트가 만나는 곳은 CON에 한 번만 정의한다**(규칙 4). 신설 3건: **[CON-02]**(런타임 모드 이벤트 — T의 상태 머신이 발행, H의 표정이 소비. [CON-01] `STATE:` 문법의 폰 내부 미러) · **[CON-03]**(수면 기록 스키마 — 02d가 쓰고 02e가 읽는다) · **[CON-04]**(프록시 API — 02a가 제공, 02b가 소비). 계약이 Draft인 동안 양측은 목업으로 진행하고, **계약 변경은 소비자 전원 합의**.
3. **절차 경계.** ADR 대역: 트래킹 앱 계보(02c·02d·02e)용 **401–499 확정**(2026-08-22 인간 승인 → [ARCH-00] §ADR bands 반영). H는 기존 101–199, 공통 셸(02a)·놀이(02b)는 301–399 — 3번째 팀원의 02b 동시 쓰기가 실제 발생하면 next free band(501–599)를 02b에 할당([ARCH-00]). Verifying 잠금([TOOL-03])과 "HANDOFF는 리드만 쓴다"([PRO-06])는 그대로.
