# [PLAN-01a] 팰 — 조도→호흡 루프

## 목표
**방이 어두워지면 팰의 호흡이 느려지고, 충분히 어두우면 잠든다.** 이 루프가 제품의 전부다. 나머지는 이걸 보이게 만드는 장치다.

## 요구사항

### 조도 입력
- BH1750 (I2C `0x23`)에서 lux를 읽는다.
- **절대값으로 판정하지 않는다.** 부팅 후 몇 초를 기준선으로 잡고 **기준선 대비 상대 변화**로 상태를 가른다. 무대 조명은 침실보다 수십 배 밝아서 절대 임계값은 무대에서 반드시 깨진다. 처음부터 상대값으로 설계할 것.
- 손으로 감싸는 동작이 명확한 하강으로 잡히는지 현장에서 실측해 임계를 조정한다.
- **⚠️ `LUX:`를 5Hz(200ms) + 데드밴드로 폰에 보낸다** — [CON-01] v0.2. 판정에만 쓴다면 1Hz도 과하지만, **폰의 표정 레이어([WO-01b-4])가 이 값으로 눈부심 반응을 만들고 1Hz면 움찔이 최대 1초 늦어 반응이 아니라 지연으로 읽힌다.** BH1750 H-res 변환이 ~120ms라 8Hz가 상한이므로 여유가 있다. 데드밴드는 어두운 방에서 BLE를 조용하게 만든다.
- **기준선 재보정 정책은 폰의 표정과 결합되지 않는다** — 폰이 glare 기준선을 자체 보유하기로 했다([CON-01] 규칙 2). 보드는 판정에 필요한 대로 재보정하면 된다.

### 상태 판정
`AWAKE → DROWSY → ASLEEP` 3상태. 전이 트리거는 **타이머가 아니라 환경**이다([IDENTITY] 상태 6종).
- `AWAKE` — 기준선 근처
- `DROWSY` — 기준선 대비 유의하게 낮음
- `ASLEEP` — DROWSY가 N초 지속 (무대용으로 N을 짧게 튜닝. 침실용 N분과 다르다)

### 후광 출력 (LED 4개, P0.13–P0.16)
| 상태 | 호흡 |
|---|---|
| AWAKE | 빠르고 불규칙 |
| DROWSY | 느려지고 깊어짐 |
| ASLEEP | 서서히 소등 |

**점이 아니라 면으로 보여야 한다.** 확산 조건은 [PLAN-01d] 소관이지만, 펌웨어 쪽에서도 4개를 개별 제어해 위상을 살짝 어긋내면 면이 더 부드러워진다.

### 잠듦 — System OFF
- `ASLEEP` 확정 후 `sd_power_system_off()` 진입, 버튼(P0.11)으로 기상.
- **깨어날 때 리셋된다 — RAM도 BLE 연결도 사라진다.** 그래서 이건 **시연의 마지막 동작으로만** 쓴다. 중간에 쓰면 재시연이 불가능해진다.
- NU-40 *모듈* 대기전류 0.4µA는 발표 소재이되, **개발보드 전체 소비전류가 아니다.** 대외 발언 시 반드시 구분([PLAN-01e]).

### 송신
[CON-01]의 메시지만 쓴다. 상태와 lux를 폰으로 보낸다. 새 메시지가 필요하면 [CON-01]을 먼저 고친다.

### 규범
- **R8** — 조도→호흡 루프는 전부 로컬. 네트워크·폰 없이도 이 루프는 돈다. 랜을 끊고 확인하는 것이 Exit gate 1.
- **R7** — 카메라를 인체 감지에 쓰지 않는다. 폴백에서 폰 카메라를 쓰더라도 용도는 **조도계(프레임 평균 휘도)** 뿐이다.

## 알아둘 값
```
버튼   P0.11 P0.12 P0.24 P0.25      LED  P0.13 P0.14 P0.15 P0.16
I2C    BH1750 0x23 · MPU-6050 0x68 · DRV2605L 0x5A
보드   Tools > Board > NUBoards nRF52 > NU40DK nRF52840
부트로더  RESET 빠르게 두 번 → 맥박 LED → 포트 재선택 (UF2 드라이브 BARAM-NU40)
```
※ `P0.xx`는 물리 포트 번호이고 Arduino 핀 번호와 1:1이 아니다. `pin_finder.ino`로 30초 안에 매핑을 확정한 뒤 숫자를 박는다.

## 폴백
| 깨지는 것 | 대응 |
|---|---|
| BH1750 못 받음 (선착순) | 폰 카메라 조도계. 발표에서는 오히려 "실제 제품은 보드 센서를 씁니다 — 침실에 카메라를 두고 싶은 사람은 없으니까요"가 좋은 답이 된다 |
| BLE 끊김 | RESET 더블탭 → 부트로더 → 포트 재선택. 무대에서는 예비 보드로 교체 |
| System OFF에서 안 깨어남 | RESET 한 번. 마지막 동작으로만 배치한 이유 |

## 작업 후보 (WO로 분해할 단위)
1. 보드 2대 살리기 — `pin_finder.ino`로 핀 매핑 확정 → Blink *(11:30, 20분)*
2. BLE UART 스캐폴드 업로드 + 폰 연결 확인 — **생명선. 12:20 데드라인** *(11:50, 30분)*
3. BH1750 주소 확인 → lux 읽기 → BLE 송신 *(12:20, 40분)*
4. 후광 3상태 호흡 — **여기에 시간을 더 쓸 것** *(13:00, 40분)*
5. System OFF + 버튼 기상 *(15:00, 40분)*
6. 예비 보드에 동일 펌웨어 동기화 *(15:40)*
