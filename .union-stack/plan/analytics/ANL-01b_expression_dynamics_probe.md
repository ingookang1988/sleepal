# [ANL-01b] 표정 동작 계측

**방법.** 실제 `app/index.html`(BUILD 2026-11-05c, main `fc3aebb`)을 Chromium 헤드리스로 띄우고 `SP._step(ms)` 로 60fps 를 결정적으로 밟으며 프레임마다 눈 높이·눈꺼풀·깜빡임·표정 채널·시선·입·fx 를 기록했다(`scripts/expr-probe.js`). 미적 판단은 없다 — 숫자와 코드 구조만 본다. 폰 실기·확산지 뒤의 가독성은 별도([WO-01d-3] 이후).

## 발견(근인 순)
1. **표정 슬롯이 하나고 크로스페이드가 없다** — `EMO` 를 새 트리거가 덮어쓰면 이전 채널(아래꺼풀 등)이 다음 프레임에 0 으로 떨어진다. 놀이에서 반응이 연달아 오면 얼굴이 튄다. 근인: `exprTrigger` 가 `EMO.t = 0` 으로 리셋, 이전 봉투의 릴리스를 타지 않는다.
2. **DROWSY 에 표류가 0** — `drift = AWAKE 1 · MORNING 0.6 · 그 외 0`. 눈꺼풀이 반쯤 내려온 채 완전히 정지하므로 "죽은 눈"(코드 주석이 경계한 바로 그것)이 졸림에서 생긴다. 깜빡임 사이 4~5초가 전부 정지.
3. **호흡이 상태와 무관하게 같은 진폭(±2%)** — [CON-01] 주기는 상태별이지만 진폭은 고정 0.9mm. 10m 에서 1.8mm p2p 는 거의 안 보이고, 감긴 눈은 0.6mm 라 후광(보드)만 숨쉬고 얼굴은 멈춘 것처럼 읽힌다.
4. **졸림이 이진이다** — 모드 머신은 `mode:progress`(후보·경과/필요)를 1Hz 로 내지만 얼굴은 소비하지 않는다. WIND_DOWN 진입 순간 DROWSY 로 한 번 바뀌고, 5분 동안 "점점 더 졸려"가 없다. [CON-01] 규칙 2 가 허용하는 *연속 표정 변조*의 빈자리.
5. **sad 가 멀리서 약하다** — 기울기 −5°와 아래꺼풀 0.12, 입꼬리뿐. 윗꺼풀 처짐이 없어 happy·curious 대비 신호량이 작다.
6. **curious 의 좌우 비대칭 6.3mm** 는 근거리용이다. 10m 신호(눈꺼풀)로 번역되지 않는다.
7. **ASLEEP 의 zzz 가 MORNING 으로 4.5초 넘어온다**(LIFE 4.5s, 상태 전이 시 미제거). 기지개 직후 z 가 떠다닌다.
8. **놀이 경로 startled 는 하드 블링크가 없다** — lux 경로만 `F.blinkEnv` 를 건다. 같은 kind 가 원천에 따라 다르게 보인다.
9. 좋은 것(유지): 비대칭 시상수(눈부심 0.23s/놓아줌 0.93s), 움찔·안도의 깜빡임 결합, 사카드 비대칭(0.13s/2.33s), 졸림의 무거운 깜빡임 1.44s, 하품 주기, 모든 봉투가 끝나면 픽셀 단위 원복.

## 개선 후보(우선순위 — [WO-01b-5]·[WO-01b-6] 소유 세션이 판단)
1. 표정 **크로스페이드/큐** — 새 트리거는 이전 봉투를 짧은 릴리스(0.15s)로 내리고 시작. 또는 채널 합성(아래꺼풀은 max, 기울기는 합).
2. `mode:progress` → **점진 졸림** — SLEEP 후보 경과율로 DROWSY 의 눈꺼풀 목표(0.55 → 0.75)·깜빡임 길이·주기를 연속 변조. 상태 전이는 없음(규칙 2 준수). 5분이 "보이는" 유일한 방법.
3. DROWSY **표류 + 꾸벅** — 표류 0.3, 그리고 10~20초 간격으로 눈꺼풀이 천천히 더 내려갔다 홱 올라오는 꾸벅(nod) 봉투. 10m 에서 가장 강한 졸림 신호.
4. **호흡 진폭 상태별** — DROWSY ±3%, ASLEEP 감긴 곡선 ×1.0(0.3 아님), 아침 ±2%. 후광과 같은 주기로 같은 깊이.
5. sad: 윗꺼풀 15% 처짐 추가. curious: 눈 비대칭 대신 **두 눈 동시 미세 기울기(고개 갸웃 2~3°)** + 시선 위.
6. 상태 전이 시 fx 즉시 페이드(0.3s) — zzz 잔류 제거.
7. startled 를 kind 기준으로 통일 — `exprTrigger('startled')` 안에서 하드 블링크까지.

## 미측정
