# [LSN-01b] BUILD 범프 직후 face-sheet 첫 로드는 이전 SW 캐시 모듈을 서빙한다

**증상**: 코드를 고치고 BUILD 를 올린 뒤 `face-sheet.html` 첫 실행에서 검사가 `측정 중…`에 멎거나 `SP.<신규심볼> undefined` 로 죽는다 — 새 SW(`sw.js?v=BUILD`)가 설치되는 동안 이전 버전 캐시가 `main.js` 등 셸 자산을 cache-first 로 서빙하기 때문([WO-02a-1] 전략의 의도된 동작).

**대응**: 강제 새로고침 1~2회(새 SW activate 후) → 정상. 게이트 결과는 반드시 재로드 후의 것으로 읽을 것. 근거: [ADR-116](BUILD 연동 캐시 무효화) · 관측 [WO-01b-6]·[WO-01b-5] 검증 중.
