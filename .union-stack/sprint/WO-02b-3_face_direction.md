# [WO-02b-3] FACE 디렉션 v1

**선행 자료 [WO-01b-4]. 후속 구현 [WO-01b-5] [WO-02b-2].** 코드보다 먼저 팰의 얼굴 문법을 고정한다. 이 WO는 제작 방향과 검증 기준을 정하며 프로덕션 런타임은 바꾸지 않는다.

## 목표
현재 5개 생리 상태를 보존하면서, SleepPal만의 고유 실루엣·전환 연기·AI 반응 제스처를 하나의 FACE 문법으로 정의한다. 팰 런타임은 몸통 안에서 가로 얼굴로, 설정·수면 일기는 폰을 꺼낸 뒤 세로 앱으로 보이게 화면 경계를 바로잡는다.

## 수용 기준
- [ ] `DOCK·PLAY·WIND_DOWN·SLEEP·WAKE = 158×73 가로 FACE`, `알람 설정·트래커·일기 = 거치 전/이탈 후 세로 앱` 경계를 디렉션 보드에 명시한다. 현행 세로 팰 목업을 이 경계에 맞춘다
- [ ] 기본 상태 5종(AWAKE·DROWSY·ASLEEP·NIGHT·MORNING)을 컬러/흑백 두 시트로 비교하고, **AWAKE↔MORNING은 색 없이도 구분**되게 한다
- [ ] 고유성 장치 하나를 확정한다: 기본 비대칭·눈꺼풀 곡률·좌우 시간차 중 하나. 45mm 눈·35mm 간격·10m 가독성은 보존한다
- [ ] `DROWSY × glare 1.0`의 최소 가시 개구를 정하고 기록한다. 눈이 사라지거나 화난 얼굴로만 읽히지 않아야 한다
- [ ] 일시 제스처 6종 `LISTEN·THINK·CURIOUS·DELIGHT·CONCERN·YAWN`의 시작 자세·피크·유지·복귀 키프레임을 정의한다
- [ ] 얼굴 합성 우선순위를 `NIGHT 하드 게이트 → 환경 반응 → AI 제스처 → 깜빡임 → 미세 표류`로 고정한다. 제스처는 기본 상태를 바꾸지 않고 끝나면 복귀한다
- [ ] `AWAKE→DROWSY→ASLEEP→NIGHT`와 `NIGHT→MORNING` 전환을 단순 보간이 아닌 연기 시퀀스로 스토리보드화한다. ASLEEP과 DELIGHT는 정지 모양이 겹쳐도 시간 문법으로 구분돼야 한다
- [ ] 녹음 시작 즉시 얼굴 반응, 응답 대기 THINK, 옹알이+표정 동기, 네트워크 실패 복귀를 한 타임라인으로 정의한다. 하단 녹색 듣기 점은 제거하고 캐릭터 동작으로 대체한다
- [ ] R1(언어 발화 없음) · R3(얼굴 UI화 금지) · R4(NIGHT 0) · R8(오프라인 폴백)을 디렉션 보드에서 항목별 검수한다

## 증거
`ref/mockups/sleepal-mockups.html`의 가로/세로 경계 수정 · 상태/제스처 키프레임 시트 · 컬러 제거 판독 결과 · 844×390 및 10m 축소 비교 · 규범 체크리스트.

## 진행 (2026-08-22) — 디렉션 확정값 ([ADR-123])
- **화면 경계**: 목업 v1.2 반영 — 팰 5화면 전부 가로 158×73 프레임, 트래커·알람은 세로. 대기(DOCK)도 가로다 — 거치 순간 이미 몸통 안이다.
- **AWAKE↔MORNING 흑백 구분**: MORNING 상시 포즈 = 눈 +5% + 아래꺼풀 잔잔한 ⌣ 0.15. 형태가 다르므로 색을 지워도 갈린다. 게이트 `아침 포즈 흑백 구분`.
- **고유성 장치(택1) = 좌우 시간차** — 깜빡임 우안 +60ms · 아침 개안 우안 +0.45s. 기본 비대칭(4%)·눈꺼풀 곡률(3mm)은 기존 자산으로 유지하되 서명은 시간차다.
- **DROWSY×glare 1.0 최소 가시 개구 = 5mm** — 지속 성분 한정(깜빡임은 완전 폐안). 실측 7.5~7.8mm, 게이트로 바닥 고정.
- **제스처 6종 키프레임**: 목업 디렉션 보드 타일 6장(시작·피크·유지·복귀 수치 포함). CURIOUS·DELIGHT·CONCERN·YAWN 은 [WO-01b-7] 봉투로 구현 완료, LISTEN·THINK 는 [WO-02b-2] 범위.
- **합성 우선순위 고정**: NIGHT 하드 게이트 → 환경 반응(glare·시선) → AI 제스처 → 깜빡임 → 미세 표류. 현행 런타임 코드 순서와 일치함을 확인.
- **전환 연기**: ASLEEP→NIGHT 감은 눈 잔영 한 호흡(6.5s) 후 소등 · NIGHT→MORNING 왼눈 선행 개안. ASLEEP↔DELIGHT 는 시간 문법(스파이크 진입 vs 느린 정착)으로 구분 — 보드에 명문화.
- **LISTEN 타임라인**: 녹음 즉시 LISTEN(0.15s 개시) → THINK(응답 대기·오프라인에도 로컬 구동 R8) → 옹알이+표정 → 복귀. **하단 녹색 듣기 점 제거** — 목업에서 삭제함.
- **규범 검수**: R1(입은 곡선+타원, 음소 불가) · R3(얼굴 문자 0 게이트 유지) · R4(밤 0 — 제스처·입·fx·시선 삼중 차단) · R8(LISTEN/THINK 로컬) — 각 항목 시트 게이트 또는 보드 주석으로 명시.
