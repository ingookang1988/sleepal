# [WO-01c-2] quiet space 접점

**현장에서 새로 만들지 않기 위한 준비다.** 14:20 슬롯 40분은 "붙이는" 시간이지 "만드는" 시간이 아니다.

## 목표
내일 웹앱이 quiet space를 어떻게 호출/임베드할지 **인터페이스만** 정해둔다. 구현은 현장.

## 수용 기준
- [ ] quiet space의 현재 진입점 확인 — URL인가, 함수인가, 별도 앱인가
- [ ] 아침 일기 화면 **한 장**이 어떤 형태로 붙는지 결정(iframe · 라우트 · 별도 탭)
- [ ] 프레이밍 문구 확정 — **"팰이 밤새 들은 것"**. "당신이 뭐라고 중얼거렸는지"가 아니다
- [ ] "아무것도 서버로 보내지 않습니다"가 화면에서 보이는 위치 결정
- [ ] 접합 실패 시 폴백 확인 — 화면 생략하고 [PLAN-01e] 큐시트 3:40을 삭제, 4:10으로 직행

## 증거
접점 정의 한 장(형태 + 호출 방법 + 프레이밍 문구).
