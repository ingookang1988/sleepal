# [WO-01b-5] 기본 FACE 5상태 개선

**선행 [WO-02b-3].** [WO-01b-4]의 조도 반응·시상수·R4 게이트를 보존하면서, 디렉션에서 확정한 기본 얼굴과 상태 전환을 런타임에 반영한다. AI 감정 제스처 구현은 [WO-02b-2] 범위다.

## 목표
기존 5상태의 원거리 가독성과 절제된 수면 톤을 유지하되, AWAKE/MORNING의 형태 중복과 DROWSY×눈부심의 소실 위험을 해결하고 상태 전환을 팰의 연기로 만든다.

## 수용 기준
- [ ] 눈 지름 45mm·간격 35mm·가로 전체화면·R3 얼굴 문자 0을 유지한다
- [ ] AWAKE와 MORNING이 흑백 정지 화면에서도 구분된다. MORNING은 한쪽 눈 선행→다른 눈→기지개→안정 포즈의 1회 시퀀스를 갖는다
- [ ] DROWSY×최대 glare가 [WO-02b-3]의 최소 가시 개구를 지킨다. glare 상승 0.15초·일반 하강 2.5초·안도 놓아줌 0.4초는 별도 인간 결정 없이는 바꾸지 않는다
- [ ] AWAKE→DROWSY→ASLEEP은 무거워지는 비대칭 깜빡임과 정착 동작으로 이어지고, ASLEEP→NIGHT는 최소 한 번의 호흡 뒤 완전 소등한다
- [ ] NIGHT는 화면·HUD·표정 계산 0을 유지한다. MORNING 진입 전까지 어떤 제스처도 새지 않는다
- [ ] 확정된 고유성 장치를 기본 얼굴에 적용하되 좌우 차이가 결함·사시처럼 보이지 않는지 실기 확인한다
- [ ] 실제 폰과 몸통에서 AWAKE·DROWSY 눈의 침실 휘도를 조정한다. 코드 색상만 보고 끝내지 않고 확산·후광을 함께 촬영한다
- [ ] `face-sheet.html`에 흑백 비교·최대 glare 최소 개구·전환 키프레임 게이트를 추가하고, 반복 새로고침에서도 검사 완료가 안정적으로 나온다

## 증거
기존 FACE 게이트 전부 통과 + 신규 실루엣/키프레임 게이트 · 844×390 폰 영상 · 몸통을 통한 침실 밝기 영상 · 1/10 축소 상태 판독 기록.

## 진행 (2026-08-22) — 구현 완료분
- **MORNING 포즈·시퀀스**: 상시 포즈 = 눈 +5% + 아래꺼풀 ⌣ 0.15(expression.js — 흑백 구분). 감은 채 진입 시 **왼눈 선행 개안**(우안 +0.45s, `F.mornStagger`) → 기지개는 1.1s 지연(eyes.js 타이머) → 안정 포즈. 뜬 채 진입하면 시간차 생략(윙크 오동작 방지).
- **DROWSY 최소 가시 개구 5mm**: main.js `MIN_APERTURE` — 지속 성분(상태 눈꺼풀+settle)에만 클램프, 깜빡임은 완전 폐안 유지. 계측 `F.apNow`.
- **고유성 장치 — 좌우 시간차**: 깜빡임 우안 +60ms(전 상태), 종료 판정은 両눈 완료 기준(오른눈 팝 방지). 계측 `F.blinkNow2`.
- **ASLEEP→NIGHT 소등 연기**: 감은 눈(⌣) 잔영이 **한 호흡(6.5s = BREATH.ASLEEP)** 머문 뒤 소등. 직전 상태의 눈 색을 유지(NIGHT #000 으로 덮으면 잔영이 즉사). R4 무관 — 시간 기반 퇴장 연기이고 lux 주입 게이트는 문자열 단위로 그대로 통과.
- **glare 시상수 불변**: 0.15 / 2.5 / 0.4 그대로 — 수용 기준의 금지선 준수, 시트 놓아줌 게이트 회귀 무손상.
- 시트 반복 새로고침 안정: [WO-01b-7]에서 도입한 준비 폴링(고정 900ms 제거)로 충족.
