# [WO-01d-3] 1호기 조립 · 검증

**선행 [WO-01d-2].** 소요 약 25분 + 검증.

## 목표
폰이 우측 개구로 미끄러져 들어가 스토퍼에서 멈추고, 화면이 확산지 개구에 정렬되며, LED가 **점이 아니라 면**으로 비치는 몸통 1개.

## 수용 기준
- [ ] 확산지를 창 전체에 앞면 **안쪽**으로 붙인 뒤 **화면 크기만큼 중앙을 잘라낸다**
- [ ] 흰 A4를 뒷면·좌측면 안쪽에 덧대 반사면 확보 — 보드가 직사이므로 **필수**
- [ ] 레일 조립 — ⑩ 받침(14/19/14)을 ⊓로 접어 바닥 Z 5–19에, 그 위에 ⑪ 채널(15/12/15)을 ⊔로 접어 얹고, 채널 안 X 18.5에 ⑨ 스토퍼 2겹
- [ ] 바닥 위에 좌측면 → 뒷면 → 앞면 → **우측 두 조각** → 윗면. **안쪽에서** 테이프
- [ ] **바닥은 한쪽만, 윗면은 뒤쪽 한 변만** 붙여 둘 다 여닫이
- [ ] 다리 3겹 10mm
- [ ] **§10-1** 폰이 우측 개구로 걸림 없이 미끄러지는가 — 걸리면 개구 높이(84)나 채널 홈을 넓힌다
- [ ] **§10-2** 스토퍼에서 멈췄을 때 화면이 확산지 개구에 정렬되는가 — 어긋나면 **스토퍼를 옮긴다.** 개구는 건드리지 말 것
- [ ] **§10-3** 폰을 손가락으로 집어 뺄 수 있는가 (우측 15.5mm 틈)
- [ ] **§10-4** 폰이 확산지에 닿지 않는가 · **채널 홈에서 헐겁지 않은가**(헐거우면 한쪽 벽 안에 골판지를 덧댄다)
- [ ] **§10-5** LED 점등 시 확산지가 점이 아니라 면으로 보이는가
- [ ] **§10-6** 바닥·윗면이 실제로 여닫히는가
- [ ] **§10-7** 들었을 때 우측이 벌어지지 않는가 — **가장 약한 면이다**

## 증거
폰을 넣은 상태의 점등 사진 + §10 7항 각각의 통과 여부.
