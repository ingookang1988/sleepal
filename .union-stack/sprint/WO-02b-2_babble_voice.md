# [WO-02b-2] 옹알이 발화

**선행 [WO-02a-2] [WO-02b-3].** 팰은 사람 말을 하지 않는다 — 미니언즈처럼 고유 발화. TTS 불요: 음절 샘플 절차 합성(동물의 숲 방식)이라 오프라인·무비용·캐릭터 통제 전부 얻는다([PLAN-02] §1).

## 목표
[WO-02b-1]의 반응 JSON(`emotion`·`babbleTone`)을 받아 옹알이 소리 + 표정([CON-02] 이벤트)으로 동시에 표현한다.

## 수용 기준
- [ ] 음절 샘플 6~10개(녹음 또는 Web Audio 합성) → 이어붙임 + 피치·속도 변조로 감정 구분(기쁨·호기심·서운함 최소 3종)
- [ ] `face/babble.js` (H 소유 파일) — Web Audio 만, 라이브러리 0
- [ ] 발화 중 표정 동기: [CON-02] 표정 트리거를 같은 타이밍에 발행 — 수신부는 [WO-01b-7] 구현 완료(**눈과 입이 함께 말한다** · 기존 kind 어휘는 [CON-02] v0.2, [WO-02b-3] 6제스처 어휘로의 확장은 착수 시 합의)
- [ ] 반응 JSON의 `emotion`·`expression`을 [WO-02b-3]의 6개 일시 제스처로 결정적으로 매핑하고, 제스처 종료 뒤 현재 기본 상태로 복귀
- [ ] 녹음 시작의 LISTEN → 응답 대기의 THINK → 옹알이+표정 → 복귀 타임라인을 구현. 별도 녹색 상태 점은 얼굴에 두지 않는다
- [ ] 네트워크 지연·실패 중에도 로컬 LISTEN/THINK/폴백 제스처가 동작해 팰이 멈춘 UI처럼 보이지 않는다(R8)
- [ ] R1 준수 — 옹알이는 언어가 아니다: 알아들을 수 있는 단어 금지
- [ ] NIGHT 0 (R4) · 볼륨은 [WO-02c-1] 믹서 경유(사운드와 충돌 없이)

## 증거
감정별 옹알이 청취 캡처 · 표정-소리 동기 육안 확인 · NIGHT 주입 시 발화 0.
