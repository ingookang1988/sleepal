# [WO-01b-5] 이산 표정·입·fx

**선행 [WO-01b-4].** 인간 결정(2026-08-22 대화): 표정 분석·제안 중 "①트리거 수신부 + ②아래꺼풀 + 입 + 특수 효과(zzz·음표)" 채택. [WO-02b-2] 옹알이(3감정 표정 동기)의 수신 측 선행 작업이다.

## 목표
[WO-01b-4]의 연속 표정(glare) 위에 **이산 표정(사건·봉투)**과 **입·도상 레이어**를 합성한다. 채널이 전부 0이면 b-4와 픽셀 단위로 동일 — 순수 추가.

## 구현 (2026-08-22)

### ① 이산 표정 트리거 수신부 — `face/expression.js`
- [CON-02] `expr:trigger {kind, tone}` 를 palBus 에서 구독. kind 어휘는 **serve.js `PAL_SYSTEM` emotion enum 재사용**: `happy`(기쁨)·`curious`(호기심)·`sad`(서운함). tone 은 0~1 수 또는 babbleTone 문자열(soft 0.6 · bright 1 · drowsy 0.35).
- 봉투(atk·hold·rel): happy 1.9s · curious 1.6s · sad 2.6s. 끝나면 채널 전부 0 → 기하 산술적 원복.
- 채널 → 기하: happy = 아래꺼풀 0.62 + 입꼬리 ↑ / curious = 좌 +6%·우 −8% 높이 + 입 'o' / sad = **눈꼬리 −5°(찡그림과 부호 반대 = 바깥 처짐)** + 입꼬리 ↓.
- **EMO_GATE** — AWAKE 1 · DROWSY 0.5 · MORNING 1 · **ASLEEP/NIGHT 0**([CON-02] 규칙 2 이중 방어). NIGHT 는 `expression()` 최상단 R4 게이트가 EMO 자체를 버린다.
- 상태 전이 유발 0([CON-01] 규칙 2) — 시트 게이트로 고정.

### ② 아래꺼풀 — `face/eyes.js` `lowLidPath()` + 마스크 `lidL2/R2`
웃는 눈 ⌣ 은 위가 아니라 아래에서 만들어진다. 위꺼풀의 거울(윗변 가운데가 arch 만큼 올라옴). low=0 이면 눈 바닥 5mm 아래에 숨고 arch 도 0 — 눈에 닿는 경로가 없다.

### 입 — `face/mouth.js` (신규, H 소유)
- 곡선 1개(닫힘) + 타원 1개(하품·"후—") — **R1: 음소(viseme) 형태 없음.**
- 기하: 중심 (79, 63.5) · 폭 12~20mm · 눈 최저점(59.9)과 간격 게이트로 분리. 눈보다 얇고(3 vs 5) 옅게 — ASLEEP 감긴 눈 ⌣ 와의 혼동 완화(ASLEEP 입 opacity 0.28).
- 동기: 하품(DROWSY 주기 14~22s · MORNING 진입 1회, [WO-01b-3] 하품 오디오와 접점) · 안도 발화 시 "후—"(relief 엣지) · 움찔 시 다뭄(g 로 폭 축소) · 호흡 ±1% · 표류 절반 추종.
- ⛔ R4 — NIGHT 계산 없이 숨김.

### 특수 효과 — `face/fx.js` (신규, H 소유)
- **zzz**: ASLEEP 에서 오른눈 오른쪽(x≥143)에서 2.6~4.2s 간격 스폰, 동시 3개 상한, 위로 떠오르며 소멸(4.5s).
- **음표**: `expr:trigger {kind:'note'}` 1발 또는 음악 모드(setMusic) 자동 스폰 — 두 눈 사이 회랑(x 66~92)을 타고 오른다(3.6s). 발행자는 [WO-02c-1] 사운드 예정, 지금은 디버그·키(9·0) 경로.
- **R3 해석([ADR-119])**: `<text>` 아님 — `<path>`/`<use>` 도형이고 눈 영역 교차 0 을 게이트로 고정. R4 — NIGHT 진입 1프레임 안에 전부 제거.

### 수동 트리거 (발화자 부재 동안)
