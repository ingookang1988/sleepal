# [WO-02c-1] 내장 사운드

**선행 [WO-02a-2].** 유튜브 뮤직은 "공존"으로 확정(HISTORY 2026-08-22 — 재생 제어 공개 API 없음). 수면 사운드는 앱이 소유해야 [WO-02d-1] 모드 전환과 연출(진입 시 서서히 감쇠)이 가능하다.

## 목표
백색소음·수면 사운드 3종 이상을 재생·볼륨 조절하고, 모드 전환 이벤트에 페이드로 반응한다.

## 수용 기준
- [ ] 로컬 오디오 파일(레포 동봉, 라이선스 명시) + Web Audio GainNode 믹서 — `sound.js` (T 소유)
- [ ] SLEEP 진입([CON-02] 수신) 시 N분에 걸친 페이드아웃 · WAKE 시 상쾌한 페이드인(선택)
- [ ] 옹알이([WO-02b-2])와 채널 분리 — 사운드 재생 중에도 팰 발화가 들린다
- [ ] 화면 꺼짐 없이(Wake Lock 전제) 8시간 연속 재생 시 메모리 증가 없음
- [ ] UI 는 WIND_DOWN 화면에만 — 얼굴 위에 컨트롤을 얹지 않는다(R3)

## 증거
3종 재생·볼륨·페이드 캡처 · 1시간 연속 재생 메모리 스냅샷 · SLEEP 전환 연동 확인.
