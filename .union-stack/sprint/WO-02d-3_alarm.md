# [WO-02d-3] 알람

**선행 [WO-02d-1](모드 머신) · [CON-03] v0.2 합의.** [PLAN-02] §시연 6·7. 사용자가 등록한 알람으로 팰이 깨우고, 반복(스누즈) 횟수로 기상까지 걸린 시간을 추적한다. 파트 **T**.

## 목표
알람 등록 → SLEEP 중 시각 도달 시 팰이 깨움(사운드+표정) → 반복 횟수와 알람 전 기상 여부가 [CON-03]에 남는다.

## 수용 기준
- [ ] 알람 등록 UI — 위치는 착수 시 결정(트래커 기록 화면 [WO-02e-1] 또는 팰 런타임 설정면). 저장은 로컬(온디바이스)
- [ ] **R4 관계 명문화** — 알람은 사용자가 명시 등록한 유일한 밤 시간 행동. SLEEP 중 팰은 여전히 아무것도 하지 않으며, 알람 시각에만 WAKE 시퀀스를 연다(등록 없으면 어떤 소리도 내지 않는다)
- [ ] 울림 = 팰 표정 + 사운드([WO-02c-1] 라이브러리 재사용) · 표정 연계는 [CON-02] 이벤트로(직접 조작 금지)
- [ ] 반복(스누즈) 1회마다 [CON-03] `alarm_ring` 이벤트 + `alarm.rings` 증가 — 기상 소요 시간의 원자료
- [ ] **알람 전 기상 감지 시**(음성·이탈·명령 — [WO-02d-1]) 알람 자동 해제 + `wake.beforeAlarm: true` 기록
- [ ] 중지 방법: 명시 명령("나 지금 일어났어") 또는 거치 이탈 — WAKE 전환은 모드 머신([WO-02d-1])이 소유

## 증거
가상 시계로 알람 도달→울림→스누즈 2회→중지 시나리오 게이트 · 실기 1회(설정→울림→중지) + IndexedDB 에 rings·beforeAlarm 확인.
