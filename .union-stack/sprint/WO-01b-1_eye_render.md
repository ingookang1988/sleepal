# [WO-01b-1] 눈 5상태

**오늘 밤에 하는 이유** — [PLAN-01b]의 갭. 원본 타임박스에 눈 렌더 슬롯이 없다(그 문서는 얼굴이 OLED이던 시절에 쓰였다). 현장 5시간을 여기 쓰면 조도→호흡 루프가 죽는다.

## 목표
상태값을 넣으면 눈이 바뀌는 화면. **BLE 없이 손으로 상태를 바꿔가며** 5가지가 전부 나와야 한다.

## 수용 기준
- [ ] 눈 지름 **45mm** · 간격 **35mm** · 가로 전체화면 · 회전 잠금 · 주소창 숨김 · Wake Lock 상시
- [ ] 5상태 — 각성(크게 뜸·가끔 깜빡) / 졸림(눈꺼풀 반쯤·느린 깜빡) / 잠듦(감김 ⌣) / 밤(없음) / 아침(뜨기·기지개)
- [ ] 배경 남색 → 호박색 → 검정, transition 2~3초
- [ ] 눈꺼풀 = 눈 위 배경색 사각형 `translateY`. 감긴 눈 = `stroke-linecap:round` 곡선. 깜빡임 0.12초
- [ ] **[ARCH-01] R3 — 눈 영역에 문자가 하나도 없다.** 디버그 값도 안 된다(필요하면 별도 화면/콘솔)
- [ ] **[ARCH-01] R1 — TTS·음성 안내 경로가 코드에 존재하지 않는다**
- [ ] 상태를 수동으로 바꾸는 임시 스위치(키보드 1~5 등). 현장에서 [CON-01] `STATE:`로 갈아끼운다

## 하지 말 것
**애니메이션 라이브러리를 쓰지 않는다.** SVG 두 개와 CSS transition이면 끝난다. 5시간짜리 작업이 아니다.

## 증거
5상태 캡처 + 10m 떨어져 "졸림"이 읽히는지 육안 확인.

## 진행 (2026-08-22)
구현 완료 — `app/index.html` 단일 파일. 검증 하네스는 `app/face-sheet.html`이고 **앱을 iframe으로 실행한다**(그림을 옮겨 그리지 않는다 — `cut-sheet.html`이 [DOM-01]에서 손으로 옮겨져 동기화가 끊긴 것과 같은 실수를 피한다).

```bash
node scripts/serve.js          # → http://localhost:5173/app/face-sheet.html
```

**기계 검사 8/8 OK** — R1 발화 경로 0 · R3 얼굴 문자 0 · `<text>` 0 · viewBox 넘침 0 · 눈 지름 45.00 · 간격 35.00 · 좌우 여백 16.50/16.50 · 5상태 15/15 프레임.
**[CON-01] 해석 6/6 OK** — `STATE:`→상태 · `SLEEPING`→밤 · 밤에서 `HELLO`→아침 · 밤이 아닐 때 `HELLO` 무시 · 알 수 없는 메시지 무시(규칙 5) · **lux 10샘플 주입에도 상태 전이 0**(규칙 2).
깜빡임 실동작 확인 — 눈꺼풀 이동량 40.05mm.

### 남은 수용 기준 (인간·실기)
- [ ] **10m 가독성 육안 확인** — 시트의 1/10 축소 행에서 각성/졸림 구분. 안 되면 졸림 눈꺼풀 L=0.55를 더 내린다
- [ ] **폰 실기** — 전체화면·회전잠금·Wake Lock. 정의상 [WO-01b-2]
- [ ] **색 튜닝은 [WO-01d-3] 이후** — 이 화면은 트레이싱지 뒤에서 보인다. 확산지가 색을 따뜻하게 밀고 휘도를 깎으므로 조립 전 튜닝은 무의미하다
