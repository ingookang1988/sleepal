# [WO-01c-1] 케어 문장 5종

**네트워크가 죽어도 시연이 살아남게 하는 장치다**([ARCH-01] R8). AI는 문장을 다듬는 데만 쓰고, 끊기면 이 5개로 폴백한다. 관객은 차이를 모른다.

## 목표
상태별 문장 5개가 코드에 박혀 있고, 전부 R2 검수를 통과한 상태.

## 수용 기준
- [ ] 상태 5종(각성·졸림·잠듦·밤·아침) 각 1문장 이상
- [ ] **[ARCH-01] R2 — 주어가 전부 팰이다. 2인칭 금지**
  - ❌ "조명이 너무 밝습니다" → ✅ "팰이 눈부셔서 눈을 못 감고 있어요"
  - ❌ "너무 시끄럽습니다" → ✅ "팰이 자꾸 깨요"
- [ ] **[ARCH-01] R6 — 수치·점수·등급·비교가 없다.** lux 값을 문장에 넣지 않는다
- [ ] **[ARCH-01] R4 — 밤 상태 문장은 화면에 표시되지 않는다.** 문장은 존재하되 밤에는 출력 경로가 막혀 있다
- [ ] 대시보드가 아니라 **한 줄 문장**이다

## 증거
문장 5종 전문 + 각 문장의 R2·R6 통과 여부.
