# 슬립팰 (SleepPal)

## 한 줄 정의
> 사용자보다 먼저 졸려 하고 먼저 잠드는 **반려 수면등**. 사용자는 팰을 재우려고 방을 어둡고 조용하게 만들고, 잠들기 전 자기 폰을 도크에 올려 얼굴을 빌려준다 — 그 과정에서 자신이 잠들 준비를 마친다.
>
> *수면등은 사람이 끈다. 팰은 자기가 잠든다.*

## 푸는 문제
잠들기 직전까지 폰을 본다. 진짜 원인은 화면 중독이 아니라 **혼자 자는 밤의 외로움**이다. 기존 수면 앱은 잠들려고 폰을 열게 만들고 아침에 점수를 줘서 문제를 악화시킨다(오소솜니아 — 추적할수록 불안이 커져 못 자는 현상).

## 핵심 원리
- **수면의 사회적 전염**을 사물로 구현한다. 하품이 옮듯, 곁의 존재가 먼저 잠들면 사람도 잠든다.
- **돌봄의 방향을 역전**한다. 제품이 지시하지 않고 사용자가 팰을 돌본다. 지시에는 저항이 생기지만 돌봄에는 생기지 않고, 실패해도 죄책감이 아니라 안쓰러움이 남는다.

## 3층 구조 (역할이 겹치면 무너진다)
| 층 | 역할 | 표현 수단 |
|---|---|---|
| 팰 — 몸 | 상태를 몸으로 드러낸다. 말하지 않는다 | NU-40 DK · LED 4개 후광 |
| 폰 — 얼굴·목소리 | 본다 · 듣는다 · 숨쉰다 · 기록한다 | 눈 · 숨소리 · 조도 · 마이크 |
| 앱 — 통역사 | 팰의 상태를 설명한다 | 케어 문장 · 아침 일기 |

눈은 **상태**를 말하고 앱은 그 **이유**를 말한다. 앱이 사용자를 직접 평가하는 순간 돌봄 구조가 무너진다.

## 스코프 경계
- **안:** 폰 웹앱(눈·상태머신·케어 문장·아침 일기) · NU-40 DK 펌웨어(조도→호흡 루프·BLE·System OFF) · 하드웨어(몸통 도면·확산·폰 투입 레일·전력) · quiet space 접합.
- **밖:** 음성 대화 · 수면 점수/리포트 · 카메라 인체 감지 · 의료 효능 주장 · 구독으로 잠그는 핵심 기능 · 아동 타깃. 각각의 근거는 [ARCH-01].

## 규범
설계 규율 8개는 **[ARCH-01]**. 취향이 아니라 *위반 시 제품이 무너지는 규칙*이며, 카피 검수와 코드 리뷰 기준으로 그대로 쓴다. 작업 진입 시 반드시 fetch할 것.

## 도메인 어휘
| 용어 | 정의 |
|---|---|
| 팰 | 몸통 하드웨어. 사용자가 돌보는 대상. 말하지 않고 죽지 않는다 |
| 후광 | LED 4개 + 확산지가 만드는 호흡 광원. 점이 아니라 **면**이어야 한다 |
| 얼굴을 빌려준다 | 폰을 몸통 오른쪽으로 밀어 넣어 팰에게 눈을 주는 잠자리 의식. 폰이 안으로 사라지므로 돌아가려면 꺼내야 한다 |
| 케어 문장 | 팰의 상태를 앱이 옮긴 문장. 주어는 항상 팰이고 2인칭은 금지 |
| 아침 일기 | 밤새 들은 혼잣말의 회고. "팰이 밤새 들은 것" (quiet space 자산) |
| 상태 6종 | 대기·각성·졸림·잠듦·밤·아침. 전이 트리거는 타이머가 아니라 **환경과 사용자 행위** |
| System OFF | 팰이 잠들면 nRF52840이 완전 정지. "진짜로 잔다"의 물리적 근거 |
