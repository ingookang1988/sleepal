# [PHASE-01] P0 — 해커톤 데모

## 테제
> **"팰이 먼저 잠든다"가 실제로 감정을 만드는가.** 관객이 팰을 보고 하품하는가.

P0가 검증하는 것은 완성도가 아니라 *기전(mechanism)*이다. 5시간짜리 산출물은 어차피 조악하고, 무대에서 갈리는 것은 심사위원이 팰을 손에 쥐고 재우는 30초다.

| 항목 | 값 |
|---|---|
| 행사일 | 2026-08-22 (D-1 = 2026-08-21) |
| 제작 창 | 11:30 – 16:30 (5시간). **16:30 이후 컴파일·업로드 금지**, 유지보수만 |
| 발표 | 17:30 – 18:40. 무대에서 직접 시연 |
| 반입 금지 | 접착제 · 도료 · 절단 공구 → **몸통은 D-1에 완성해서 가져간다** |
| 지급 | NU-40 DK 팀당 2대(1대는 예비기) · Qwiic 케이블 · MPU-6050. 추가 I2C는 선착순 인당 2개 |

## 범위 (P0에 들어가는 것)
- NU-40 DK + BH1750 조도 → LED 4개 후광 호흡. **이 루프가 제품의 전부다**
- 폰 웹앱: 가로 전체화면 눈(SVG + CSS transition) · 상태 전이 · 케어 문장 · Wake Lock
- 숨소리 · 하품 (폰 스피커)
- quiet space 접합 — 아침 일기 화면 한 장. **새로 만들지 않고 붙이기만 한다**
- 골판지 가로형 몸통 200×130×65mm 2개 (D-1 제작)
- 팰이 잠들면 `sd_power_system_off()` → 버튼(P0.11)으로 기상

## 범위 밖 (P0에서 하지 않는 것)
서보 꾸벅꾸벅 · 무선 충전 · 베개 유닛 · 온디바이스 STT · 네이티브 앱 · MPU-6050 뒤척임 감지(있으면 좋은 것이지 필수 아님). [ARCH-01] 규율 위반 항목은 P0 이후에도 영구 제외.

## Exit gate (하나라도 미충족이면 P0 미달)
1. **조도→호흡 루프가 네트워크 없이 돈다** — 랜을 끊고 시연이 그대로 성립한다 ([ARCH-01] R8)
2. **심사위원이 팰을 손으로 감싸면 3초 안에 호흡이 느려진다** — 개별 반응이 관객에게 보인다
3. **팰이 스스로 잠든다** — LED가 서서히 꺼지고 눈이 감기며, 사용자가 끄는 동작이 없다
4. **배터리 단독으로 전 시연이 완주된다** — USB 없이
5. **[ARCH-01] 검수 체크리스트 8항이 데모 경로에서 전부 통과** — 특히 R2(2인칭)·R6(채점)
6. **예비 보드에 동일 펌웨어가 올라가 있다** — 무대에서 죽으면 바꿔 끼운다
