# [PHASE-02] P1 — PWA 제품화

## 테제
> **"매일 밤 팰과 함께 잔다"가 데모 없이도 성립하는가.**

P0가 무대 30초의 기전을 검증했다면, P1은 그 기전을 **하룻밤 전체**로 편다 — 잠들기 전 외로움(놀이) → 수면 환경 조성(사운드) → 자동 수면 전환(트래커) → 기상. 발표 시 PWA로 설치·시연한다.

## 범위
- PWA 요건: 매니페스트 · 서비스워커 · 설치 가능(HTTPS는 Railway 기존)
- 놀이: 음성 녹음→STT→LLM, 팰은 옹알이(고유 발화)+표정으로 응답
- 수면 사운드: 백색소음·수면 음악 **앱 내장**(Web Audio). 유튜브 뮤직은 "공존"(사용자 백그라운드 재생, 제어하지 않음)
- 모드 자동 전환: 조도·수음 5분 히스테리시스 + 명시 명령("나 이제 잘게"/"나 지금 일어났어")
- 수면 트래커 v1: **마이크 기반**(코골이 + 조도/소음 타임라인) · 온디바이스 · IndexedDB
- 트래커 기록 화면: Vite + React (착수 시점 도입 — HISTORY 참조)

## 범위 밖 (로드맵 — P1 이후)
- **배게 IMU 유닛** — 뒤척임 정밀 검출. 폰이 팰 안에 있어 마이크로는 뒤척임이 거칠게만 잡히므로, 배게에 IMU를 내장해 BLE로 연결하는 것으로 해결한다(인간 확정 2026-08-22). [PHASE-01]에서 범위 밖이던 "베개 유닛 · MPU-6050 뒤척임"의 재진입 경로다.
- 음성 실시간 대화(Realtime) — 녹음→STT로 시작하고, 지연이 UX를 깨는 것이 실측될 때만 재검토

## Exit gate
1. 폰 크롬에서 PWA 설치 → 전체화면 팰 실행
2. 놀이 1왕복: 음성 입력 → 팰이 옹알이+표정으로 응답
3. 내장 사운드 재생 + 볼륨 조절
4. 수면/기상 자동 전환이 조도·수음 조건으로 시연됨
5. 밤샘 1회: 아침에 기록(코골이·환경 타임라인)이 남아 있음 — **발열·배터리 실측 포함**
